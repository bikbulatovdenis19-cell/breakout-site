# BreakOut — сайт для GitHub Pages

Это готовая предрелизная версия сайта BreakOut. В папке **нет исходников Xcode** и нет секретных ключей. Её можно выкладывать в отдельный публичный репозиторий GitHub.

## Что уже готово

- строгая тёмная стилистика BreakOut;
- фирменный зелёный акцент `#B0EB33` из текущего macOS-проекта;
- оригинальная иконка BreakOut из `Assets.xcassets`;
- адаптация под Mac, iPad/iPhone и обычные браузеры;
- переключение EN / RU на главной странице;
- описание возможностей программы;
- схема будущей лицензии: аккаунт + резервный ключ + контроль устройств;
- тарифы 6 месяцев / 1 год;
- кнопки «Скачать», «Войти», «Купить» уже стоят на правильных местах, но пока безопасно показывают сообщение о предрелизном режиме;
- страницы Privacy / Terms / Support;
- никакой рекламы, аналитических SDK и маркетинговых трекеров.

## Как посмотреть сайт у себя

Самый простой вариант: открой файл `index.html` двойным нажатием.

Или через локальный сервер в Terminal:

```bash
cd BreakOut-GitHub-Site
python3 -m http.server 8080
```

После этого открой в Safari:

`http://localhost:8080`

## Как выложить на GitHub Pages

1. На GitHub создай **отдельный репозиторий только для сайта**, например `breakout-site`.
2. Не загружай туда ZIP с Xcode-проектом BreakOut.
3. Распакуй `BreakOut-GitHub-Site.zip`.
4. Загрузи **всё содержимое папки `BreakOut-GitHub-Site`** в корень репозитория.
5. Сделай Commit в ветку `main`.
6. В репозитории открой **Settings → Pages**.
7. В разделе **Build and deployment** выбери **Deploy from a branch**.
8. Branch: `main`, Folder: `/(root)`.
9. Нажми Save.
10. Через некоторое время GitHub покажет адрес сайта вида `https://имя.github.io/breakout-site/`.

## Как позже включить настоящие кнопки

Для этого не нужно переделывать дизайн. В файле `config.js` уже подготовлены отдельные адреса:

- `downloadURL` — ссылка на готовый `.dmg`;
- `purchaseSixMonthsURL` — оплата 6 месяцев;
- `purchaseAnnualURL` — оплата 1 года;
- `signInURL` — личный кабинет;
- `registerURL` — регистрация.

Пока эти поля пустые, сайт показывает аккуратное предрелизное окно и **ничего не списывает**.

## Важно про GitHub Pages

GitHub Pages подходит для внешней части сайта, но **секреты оплаты и лицензирования туда класть нельзя**. Любой JavaScript на GitHub Pages доступен посетителю.

Поэтому в дальнейшем архитектура будет такой:

```text
Сайт на GitHub Pages
        ↓
кнопка покупки
        ↓
платёжный провайдер
        ↓
защищённый backend / webhook
        ↓
аккаунт + подписка + лицензия
        ↓
BreakOut.app проверяет лицензию по HTTPS
```

Секрет ЮKassa, приватный ключ подписи лицензий и административные ключи Supabase должны находиться только на серверной стороне.

## Как предлагается выдавать ключ

Основной способ активации — вход в аккаунт BreakOut. После успешной оплаты backend создаёт право пользования и одновременно может выдать резервный ключ вида:

`BO-XXXX-XXXX-XXXX`

Пользователь увидит этот ключ в будущем личном кабинете и сможет использовать его для ручной активации/поддержки. При этом подписка всё равно контролируется сервером, поэтому пересылка одного ZIP с приложением не передаёт право пользования.

Подробнее будущая серверная схема описана в `INTEGRATION_PLAN.md`.
